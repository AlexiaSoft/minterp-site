ข้อตกลงและเงื่อนไข

เงื่อนไขการใช้เว็บไซต์และข้อมูลเบื้องต้นก่อนเลือกใช้งาน MintERP

ปรับปรุงล่าสุด: 5 ตุลาคม 2569

หน้านี้อธิบายการใช้เว็บไซต์และหลักการให้บริการเบื้องต้น ไม่ใช่สัญญาซื้อขายหรือใบเสนอราคา การเปิดเว็บไซต์หรือนัดสาธิตไม่ทำให้เกิดคำสั่งซื้อหรือภาระชำระเงินโดยอัตโนมัติ

ขอบเขตเว็บไซต์การใช้งานราคาและแพ็กเกจงานปรับแต่งการดูแลระบบชำระและยกเลิกสิทธิและข้อมูลความรับผิดชอบการติดต่อ

1. ผู้ให้บริการและขอบเขตเว็บไซต์

เว็บไซต์ minterp.alexiasoft.co ดำเนินการโดย AlexiaSoft Company Limited เพื่อแนะนำ MintERP โมดูล ฟีเจอร์ Workflow รูปแบบราคา และช่องทางติดต่อ รวมถึงเนื้อหาในหน้า Presentation

รายละเอียดและภาพประกอบใช้เพื่อทำความเข้าใจผลิตภัณฑ์ ภาพหน้าจอที่ระบุว่าเป็นข้อมูลตัวอย่างไม่ใช่ข้อมูลผลประกอบการของลูกค้า ความสามารถที่ใช้งานจริงขึ้นกับรุ่น แพ็กเกจ โมดูล สิทธิ์ การตั้งค่า และขอบเขตที่ตรวจรับ

ก่อนตัดสินใจ กรุณาขอสาธิตกระบวนการที่เกี่ยวข้องและยืนยันรายละเอียดในใบเสนอราคาหรือสัญญา หากข้อมูลสรุปบนเว็บไซต์ต่างจากข้อตกลงเฉพาะที่คู่สัญญายอมรับ ให้ยึดข้อตกลงนั้นในขอบเขตที่ไม่ขัดต่อกฎหมาย

2. การใช้เว็บไซต์อย่างเหมาะสม

  • ใช้เว็บไซต์เพื่อศึกษาผลิตภัณฑ์ ติดต่อสอบถาม หรือวัตถุประสงค์ที่ชอบด้วยกฎหมาย
  • ไม่พยายามเข้าถึงข้อมูลหรือระบบที่ไม่ได้รับอนุญาต ไม่ส่งโค้ดอันตราย หรือรบกวนการทำงานของเว็บไซต์
  • ไม่ปลอมแปลงตัวตนหรือส่งข้อมูลที่ละเมิดสิทธิของบุคคลอื่น
  • ไม่คัดลอกเนื้อหาไปแสดงเป็นผลงานของตน หรือใช้ชื่อและเครื่องหมายของเราในลักษณะที่ทำให้เข้าใจผิดว่าได้รับการรับรอง

คุณสามารถแชร์ลิงก์หน้าเว็บไซต์และ Presentation เพื่อแนะนำผลิตภัณฑ์ได้ โดยไม่ดัดแปลงข้อมูลให้เข้าใจผิด หากต้องการนำสื่อหรือเครื่องหมายไปใช้ในกิจกรรมอื่น กรุณาติดต่อเพื่อขออนุญาตก่อน เว้นแต่เป็นการใช้ที่กฎหมายอนุญาต

3. ราคา แพ็กเกจ และสิทธิ์ใช้งาน

ราคาบน หน้าแพ็กเกจ เป็นราคาเริ่มต้นและไม่รวม VAT ค่าติดตั้ง ส่วนเพิ่ม และบริการนอกขอบเขตต้องตรวจจากรายละเอียดแต่ละรายการ ราคาสุดท้าย จำนวนผู้ใช้ สาขา คลัง และโมดูล ให้ยืนยันในใบเสนอราคาก่อนสั่งซื้อ

  • Subscription: ใช้ระบบมาตรฐานตามรอบเดือนหรือปี รวม Cloud Hosting พื้นที่จัดเก็บตามแพ็กเกจ การสำรองข้อมูล อัปเดตมาตรฐาน และ Support ตามขอบเขตที่ตกลง ไม่รวมการแก้โค้ดเฉพาะราย
  • License: สิทธิ์ใช้ระบบถาวรตามสัญญาและรวมผู้ใช้ สาขา และคลังตามแพ็กเกจ ไม่ใช่การโอนกรรมสิทธิ์ซอฟต์แวร์หรือ Source Code โดยอัตโนมัติ ไม่รวม Hosting เครื่องแม่ข่าย การสำรองข้อมูล และการดูแลโครงสร้างพื้นฐาน เว้นแต่เลือก Managed Cloud หรือระบุไว้ต่างหาก
  • Expansion Pack: ส่วนเพิ่มผู้ใช้ สาขา หรือคลังสำหรับ License เป็นสิทธิ์ถาวรและชำระครั้งเดียว ไม่มีค่าผู้ใช้หรือสาขารายเดือน การเพิ่มสิทธิ์ไม่ทำให้ค่าบริการ Managed Cloud เพิ่มขึ้นโดยอัตโนมัติ แต่ MA 18% จะคำนวณเพิ่มเมื่อรายการนั้นอยู่ภายใต้การดูแล
  • Managed Cloud: บริการเสริมสำหรับ License ครอบคลุม Dedicated Cloud Server, พื้นที่จัดเก็บ การสำรองข้อมูล Monitoring และการดูแลโครงสร้างพื้นฐานตามขอบเขตที่ตกลง ไม่รวมค่าบำรุงรักษา License งานพัฒนาเพิ่ม หรือ SLA พิเศษ
  • MA: บริการเลือกต่ออายุรายปีตั้งแต่ปีที่ 2 ครอบคลุมการบำรุงรักษา License การอัปเดตระบบมาตรฐาน และ Support ตามขอบเขตที่ตกลง หากไม่ต่อ MA ลูกค้ายังใช้ระบบเวอร์ชันที่ได้รับสิทธิ์ได้ แต่ไม่รวม Update และ Support การกลับเข้ารับบริการอาจต้องตรวจสภาพหรือปรับรุ่นและประเมินค่าใช้จ่ายก่อนดำเนินการ
  • MA + Managed Cloud: ผลรวมค่าบริการ MA และ Managed Cloud รายปี Production, Expansion Pack และ Custom Code อาจทำให้ค่าดูแลเพิ่มขึ้น
  • Production และส่วนเพิ่ม: เป็นรายการที่เลือกเพิ่มตามความต้องการ ไม่ถือว่ารวมในทุกแพ็กเกจ

ค่าบำรุงรักษาและอัปเดตมาตรฐานของ License ตลอดจนค่าเพิ่มผู้ใช้ สาขา คลัง และพื้นที่จัดเก็บ ให้ยึดอัตราและขอบเขตที่ระบุในข้อเสนอและสัญญา การปรับราคาที่แสดงบนเว็บไซต์ไม่เปลี่ยนสัญญาที่มีอยู่โดยอัตโนมัติ

4. งานปรับแต่ง เชื่อมต่อ และย้ายข้อมูล

งาน Customize สำหรับ License งานเชื่อมต่อระบบภายนอก และการย้ายข้อมูลเก่า ประเมินเป็นโครงการแยกตามความเป็นไปได้ ปริมาณข้อมูล และความซับซ้อน ไม่รวมอยู่ในค่าระบบมาตรฐานหากไม่ได้ระบุไว้

ก่อนเริ่มงาน ต้องตกลงสิ่งที่จะส่งมอบ สิ่งที่ไม่รวม ผู้รับผิดชอบข้อมูล ระยะเวลา ราคา เกณฑ์ทดสอบและตรวจรับ UAT รวมถึงการดูแลหลังส่งมอบ การเพิ่มหรือเปลี่ยน Requirement อาจกระทบราคาและกำหนดส่ง จึงต้องตกลงการเปลี่ยนแปลงก่อนดำเนินการ

ฟีเจอร์ที่ระบุว่าเป็นแผนพัฒนา ตัวเลือกเสริม หรือรอตรวจรับ ไม่ถือเป็นคำรับรองว่าจะพร้อมใช้งานในทุกโครงการ ต้องยืนยันในขอบเขตส่งมอบของคุณโดยเฉพาะ

5. การติดตั้ง Support และการดูแลระบบ

Support มาตรฐานครอบคลุมคำถามการใช้งานและการตรวจสอบปัญหาระบบในวัน/เวลาทำการของ AlexiaSoft ตามข้อตกลงบริการ ไม่ถือว่ารวมการพัฒนาเพิ่ม การแก้ไขข้อมูลทุกรูปแบบ หรือการดูแลตลอด 24 ชั่วโมง

ช่องทางรับเรื่อง ระดับความสำคัญ เวลาให้บริการหรือ SLA รอบและระยะเวลาเก็บสำรองข้อมูล วิธีทดสอบกู้คืน และการบำรุงรักษาตามแผน ต้องยืนยันตามรูปแบบบริการและสัญญา ไม่ถือว่าข้อความแนะนำบนเว็บไซต์เป็นการรับประกัน uptime หรือระยะเวลาแก้ไขทุกกรณี

ลูกค้าควรจัดผู้รับผิดชอบระบบ ตรวจสิทธิ์ผู้ใช้ รักษาบัญชีและรหัสผ่าน และตรวจสอบความถูกต้องของข้อมูลตั้งต้น กรณีติดตั้งในโครงสร้างพื้นฐานของลูกค้า ต้องกำหนดผู้รับผิดชอบเครื่องแม่ข่าย ความปลอดภัย และการสำรองข้อมูลให้ชัดเจน

6. การชำระเงิน ต่ออายุ ยกเลิก และคืนเงิน

รอบบริการ กำหนดชำระ วิธีต่ออายุ ระยะเวลาแจ้งยกเลิก การระงับหรือสิ้นสุดบริการ และเงื่อนไขคืนเงิน ให้ระบุในใบเสนอราคาหรือสัญญาที่ลูกค้ายอมรับก่อนเริ่มบริการ เว็บไซต์นี้ไม่ได้กำหนดการต่ออายุหรือตัดเงินอัตโนมัติจากการเข้าชม

กรุณาสอบถามเงื่อนไขเหล่านี้ก่อนชำระเงิน หากสิ้นสุดบริการ ควรตกลงรูปแบบการส่งออกข้อมูล ระยะเวลาขอรับข้อมูล ค่าใช้จ่ายที่อาจมี และกำหนดลบข้อมูลรวมถึงสำเนาสำรอง เงื่อนไขเฉพาะใด ๆ ต้องไม่ตัดสิทธิที่กฎหมายให้ความคุ้มครอง

7. ทรัพย์สินทางปัญญาและข้อมูลส่วนบุคคล

ชื่อ MintERP โลโก้ เนื้อหา และซอฟต์แวร์ เป็นสิทธิของเจ้าของสิทธิที่เกี่ยวข้อง การเข้าชมเว็บไซต์ไม่ให้สิทธิในซอฟต์แวร์หรือเครื่องหมายการค้าเพิ่มเติมจากที่ระบุไว้ การใช้ส่วนประกอบของบุคคลภายนอกยังอยู่ภายใต้เงื่อนไขของเจ้าของสิทธินั้น

การจัดการข้อมูลจากการเยี่ยมชมและการติดต่อเป็นไปตาม นโยบายความเป็นส่วนตัว การอ่านหน้านี้ไม่ถือเป็นความยินยอมรับการตลาดหรือการประมวลผลข้อมูลทุกประเภท

ข้อมูลที่องค์กรบันทึกในระบบ ERP และสิทธิในการเข้าถึงเพื่อให้บริการ ต้องกำหนดตามสัญญาและกฎหมายคุ้มครองข้อมูลส่วนบุคคล ลูกค้าต้องมีสิทธิหรือฐานกฎหมายในการนำข้อมูลของบุคคลอื่นเข้าระบบ การซื้อสิทธิ์ใช้ซอฟต์แวร์ไม่ได้โอนสิทธิในข้อมูลของลูกค้าให้ผู้ให้บริการโดยอัตโนมัติ

8. ความถูกต้อง ข้อจำกัด และกฎหมายที่เกี่ยวข้อง

เรามุ่งให้ข้อมูลผลิตภัณฑ์ถูกต้องและเป็นปัจจุบัน แต่อาจมีข้อผิดพลาดหรือการเปลี่ยนแปลงที่ยังไม่สะท้อนในทุกหน้า กรุณายืนยันรายละเอียดสำคัญก่อนตัดสินใจ ไม่รับรองผลลัพธ์ด้านยอดขาย กำไร ระยะเวลาเริ่มใช้ หรือความเหมาะสมกับทุกธุรกิจจากข้อมูลเว็บไซต์เพียงอย่างเดียว

MintERP เป็นเครื่องมือช่วยจัดการข้อมูลและขั้นตอนธุรกิจ ไม่ใช่คำแนะนำทางกฎหมาย บัญชี หรือภาษี ลูกค้าควรให้ผู้รับผิดชอบหรือผู้เชี่ยวชาญตรวจการตั้งค่าและเอกสารก่อนใช้งานจริง เว็บไซต์ภายนอกที่เชื่อมโยงมีเงื่อนไขของตนเองและไม่ได้อยู่ภายใต้การควบคุมของเรา

การรับประกัน การเยียวยา และความรับผิดเกี่ยวกับบริการที่ซื้อ ให้เป็นไปตามสัญญาและกฎหมายที่ใช้บังคับ ไม่มีข้อความในหน้านี้ที่มุ่งยกเว้นความรับผิดซึ่งกฎหมายห้ามยกเว้น หรือตัดสิทธิผู้บริโภคที่ได้รับความคุ้มครองตามกฎหมายไทย

9. การเปลี่ยนแปลงและการติดต่อ

เราอาจปรับปรุงเนื้อหาหน้านี้และแสดงวันที่ปรับปรุงด้านบน การเปลี่ยนเงื่อนไขบริการของลูกค้าที่มีสัญญาแล้วต้องเป็นไปตามกระบวนการในสัญญาและกฎหมาย ไม่ใช้การแก้หน้าเว็บไซต์เพื่อเปลี่ยนข้อตกลงย้อนหลังโดยอัตโนมัติ
